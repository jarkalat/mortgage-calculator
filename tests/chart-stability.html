Chart stability test

Opens every page that draws charts, redraws the charts many times (window resizes, phone and desktop widths, light and dark mode) and checks each chart keeps the same size and is still drawn. Catches charts that grow on every redraw until the browser refuses to draw them (Chrome shows a white box with a broken-content icon). Run it from a web server, e.g. python3 -m http.server in the project folder, then open /tests/chart-stability.html.
